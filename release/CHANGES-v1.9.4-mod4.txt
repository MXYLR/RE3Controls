Changes in v1.9.4-mod4
======================

FIX
- The character now stands on the expected side of the screen.  camera.cpp's
  Orbit puts the character on the left of the frame when leftShoulder = false
  (the camera is offset to its right), so the shoulder mask is now applied as
  "bit set = character on the same side as before the fix but mirrored": the
  bit means the CHARACTER is on the LEFT of the screen, and leftShoulder is its
  inverse.  Defaults: bit 0 = Chris (left), bit 1 = Sheva (right).
- The INI default line for ShoulderLeftKinds no longer carries an inline
  comment (the list parser would have read the numbers in it).

Unchanged from v1.9.4-mod3
- Shoulder swap is available at any time (Camera/ShoulderSwapAlways=1, pad RB
  or L3 with RunButton=RB, keyboard Q); the knife stays on LB.
- Per-character default shoulder (Camera/ShoulderAuto, ShoulderLeftKinds).
- Plain-gun zoom: F in, C out while aiming (Aim/ZoomKeys).
- Scope fixes, knife camera, aim pitch (see v1.9.4-mod1/2 notes).
- notencio v1.9.4 performance and behaviour fixes.
